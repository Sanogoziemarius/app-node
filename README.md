# Projet: Saisie d'un nombre javascript

## Description

ce projet permet de saisir un nombre au clavier directement dans le terminal, puis d'y afficher la valeur saisie grace au module readline pour saisir des valeur directement dans le terminal 

## exécution
on  Exécute la commande node index.js pour lancer le programme, des question qui on été préalablement difini vont s'afficher dans le terminal et Saisir un nombre lorsque le programme le demande. enfin on observer le résultat dans le terminal.

## Organisation du projet
nous avons en premier index.js qui  contient le code JavaScript. Le package.json qui contient les informations sur le projet (le nom, la version.. ). Le package-lock.json qui fixe les versions précises des dépendances et enfin le README.md qui présente le projet et explique son utilisation.
